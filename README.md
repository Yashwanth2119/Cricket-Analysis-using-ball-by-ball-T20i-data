# Cricket-Analysis-using-ball-by-ball-T20i-data-
Cricket Predictor is a small research project containing data analysis and machine-learning notebooks that explore T20 international cricket data from 2003-2023, evaluate player performance, and build models to predict match outcomes.

The link to the dataset: https://www.kaggle.com/datasets/jamiewelsh2/ball-by-ball-it20/data
